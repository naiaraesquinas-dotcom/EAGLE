{\Large\bfseries EAGLE -- WP2.3: Open-source software comparison}

\vspace{0.15cm}
{\small
\textbf{Purpose of the comparison.}
The software must ultimately support the WP2.3 chain:
\textit{Spanish network data $\rightarrow$ electrical network model $\rightarrow$ power-system analysis
$\rightarrow$ line/voltage/grid constraints $\rightarrow$ nodal hosting-capacity assessment
$\rightarrow$ spatial indicators for SiteOptimizer.}
The project proposal specifically targets HV and, where possible, MV network data, line saturation,
regional flexibility requirements and nodal grid hosting capacity.
}

\vspace{0.12cm}
{\scriptsize
\textbf{Colour code:}
\G\; capability is well aligned with the EAGLE requirement;
\PARTIAL\; capability exists or can be achieved, but is secondary, indirect, requires additional workflow,
or is not the tool's main strength;
\N\; the tool does not provide that function by itself.
}

{\scriptsize
\textbf{Interpretation note.}
The colours are a \emph{working EAGLE-oriented classification}, not a claim that a red/orange tool is
generally ``bad''. They answer the narrower question: \textit{how directly does this tool satisfy the
requirements we currently understand for WP2.3?} Hosting capacity itself is a study methodology and may
need to be implemented on top of a power-flow/OPF engine.

{\small
\textbf{Purpose of the comparison.}

supporting later grid-constraint and hosting-capacity analysis. Based on the project, the most important

\vfill
{\scriptsize
\textbf{Important data-quality note.}
The EAGLE proposal explicitly identifies poor quality, data gaps and insufficient granularity as risks for
WP2--WP4. Therefore, a source being marked \G does not mean that every required field is guaranteed for
every Spanish asset; it means that the source is a credible/usable source for that data category and should
be investigated further.

\textbf{Particularly important finding for the next phase:}
PyPSA-Eur's current transmission representation is at/above 220 kV, while Red Eléctrica reports a Spanish
transport network including 400 kV and 220 kV on the mainland and lower transport voltages in non-peninsular
systems. Therefore, the Spanish model may need a combination of PyPSA-Eur/other open topology data with
Spanish sources if EAGLE requires more detail than the European transmission model provides.

\textbf{Sources checked:}
PyPSA-Eur documentation; GridKit/Zenodo and GridKit repository; MapYourGrid; Red Eléctrica public data and

the EAGLE proposal supplied in the project.
